راهنمای مدیر پروژه

راه‌اندازی پیام‌رسان دوریا

این نسخه وب برای آزمایش اولیه ساخته شده است. برای ورود کاربران و ذخیره پیام‌ها، باید یک پروژه Supabase به آن متصل و جدول‌های پایگاه‌داده ایجاد شوند.

۱. ساخت پایگاه‌داده

  1. در حساب Supabase یک پروژه جدید بساز.
  2. از بخش SQL Editor فایل supabase/schema.sql موجود در مخزن را باز کن و یک‌بار اجرا کن.
  3. مطمئن شو اجرای همه دستورها بدون خطا تمام شده است.

۲. اتصال سایت

  1. در تنظیمات پروژه Supabase بخش API را باز کن.
  2. Project URL و کلید عمومی Publishable یا anon را بردار.
  3. در صفحه دوریا روی چرخ‌دنده بزن و فقط همین دو مقدار را وارد کن.
هشدار امنیتی: هرگز کلید service_role، کلید secret یا رمز پایگاه‌داده را در مرورگر، فایل‌های سایت یا مخزن عمومی قرار نده. کلید عمومی فقط در کنار سیاست‌های RLS درست قابل استفاده است.

۳. امکانات نسخه آزمایشی

  • ثبت‌نام و ورود با ایمیل و رمز عبور
  • نمایه و جست‌وجوی فهرست کاربران
  • گفت‌وگوی خصوصی متنی
  • ساخت گروه عمومی و گفت‌وگوی گروهی
  • به‌روزرسانی پیام‌ها با Realtime در صورت فعال بودن آن

۴. محدودیت‌های مهم

این نسخه هنوز پیام‌رسان کامل و آماده استفاده عمومی نیست. تماس صوتی و تصویری، ارسال فایل و عکس، کانال، مدیریت حرفه‌ای گزارش‌ها، اعلان‌های پوش، رمزگذاری سرتاسری و آزمون امنیتی مستقل هنوز تکمیل نشده‌اند. پیام‌ها در پایگاه‌داده به شکل قابل خواندن ذخیره می‌شوند؛ اطلاعات حساس ارسال نکن.

برای استفاده واقعی، مالک پروژه باید سیاست‌های دسترسی (RLS)، محدودیت ثبت‌نام، پشتیبان‌گیری، قوانین حریم خصوصی و روش رسیدگی به گزارش‌ها را بازبینی کند. این راهنما تضمین امنیت یا آمادگی تولید نیست.
