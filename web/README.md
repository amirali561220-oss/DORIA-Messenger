# دوریا — پیام‌رسان فارسی وب

این پوشه رابط وب DORIA را شامل می‌شود. رابط برای گوشی طراحی شده و راست‌چین است.

## امکانات فعلی
- ثبت‌نام و ورود با Supabase Auth
- نمایه با نام نمایشی و نام کاربری
- فهرست کاربران
- گفت‌وگوی خصوصی متنی
- ساخت و مشاهده گروه‌های عمومی
- عضویت در گروه و پیام گروهی
- به‌روزرسانی زنده پیام‌ها با Supabase Realtime
- ثبت گزارش کاربر
- طراحی واکنش‌گرا و قابلیت نصب به شکل PWA

## راه‌اندازی سرویس
1. در Supabase یک پروژه بساز.
2. از SQL Editor فایل `supabase/schema.sql` را اجرا کن.
3. در تنظیمات Authentication، روش Email را فعال نگه دار. برای امنیت، تأیید ایمیل را غیرفعال نکن مگر با آگاهی از پیامدهای آن.
4. در بخش API، Project URL و کلید عمومی Publishable یا anon را بردار.
5. سایت را باز کن و این دو مقدار را در صفحه «اتصال دوریا» وارد کن.
6. اگر تأیید ایمیل روشن است، ایمیل ثبت‌نام را تأیید کن و سپس وارد شو.

## انتشار سایت
این پروژه workflow انتشار GitHub Pages دارد. در مخزن، Settings → Pages → Build and deployment را روی GitHub Actions قرار بده. سپس اجرای workflow با نام Deploy DORIA web preview را در Actions بررسی کن. آدرس نهایی فقط پس از موفقیت deployment در جزئیات workflow مشخص می‌شود.

## نکات امنیتی مهم
- فقط کلید عمومی Supabase را در مرورگر وارد کن؛ هرگز service_role، secret key یا رمز پایگاه‌داده را در سایت یا مخزن عمومی قرار نده.
- پیام‌های این نسخه رمزگذاری سرتاسری (E2EE) ندارند.
- این نسخه برای آزمایش اولیه است و پیش از استفاده عمومی باید سیاست‌های RLS، محدودیت ارسال پیام، مقابله با سوءاستفاده، گزارش‌ها، حذف حساب و حریم خصوصی توسط فرد باتجربه بازبینی شوند.
- اطلاعات حساس، نشانی خانه، شماره تلفن، رمزها یا کدهای تأیید را برای کاربران ناشناس نفرست.
